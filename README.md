# 🛒 Superlista - Supermarket List PWA

Este é um aplicativo de lista de supermercado simples e funcional, desenvolvido como parte da avaliação de programação mobile. O app permite gerenciar itens de compra de forma rápida, com uma interface intuitiva e suporte a PWA (Progressive Web App).

## 🚀 Funcionalidades

- **Adicionar Itens:** Digite o nome do produto e adicione à lista.
- **Remover Itens:** Exclua produtos da lista clicando no ícone de lixeira.
- **Interface Responsiva:** Otimizado para dispositivos móveis e desktop.
- **PWA Ready:** Pode ser instalado no celular através do navegador.
- **Easter Egg:** Tente clicar no ícone de lista vazia para descobrir uma surpresa! 🎁

## 🛠️ Tecnologias Utilizadas[

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [Expo Vector Icons](https://icons.expo.fyi/) (MaterialIcons)
- [Vercel](https://vercel.com/) (Hospedagem)

## 📦 Como rodar o projeto localmente

Antes de começar, você precisará ter instalado em sua máquina:

1.  **Node.js**: Versão **18.x** ou superior (recomenda-se a versão LTS).
2.  **Gerenciador de Pacotes**: **npm** (que já vem com o Node).
3.  **Git**: Para clonar o repositório.
4.  **Expo CLI**: Não é necessário instalar globalmente, pois utilizaremos via `npx`, mas é necessário ter permissão para executar scripts no terminal.
5.  **Navegador Web**: (Chrome, Firefox ou Edge) para visualizar a versão Web/PWA.
6.  **Expo Go (Opcional)**: Caso queira testar as funcionalidades nativas no celular (disponível na Play Store/App Store).

7.  Clone o repositório:

```bash
   git clone https://github.com/lauraonline/superlista.git
```

2. Entre na pasta:

```bash
   cd superlista
```

3. Clone o repositório:

```bash
   npm install
```

4. Inicie o projeto:

```bash
   npx expo start
```

Pressione `w` para abrir no navegador.

## 🌐 Deploy e Instalação (PWA)

O projeto está hospedado na Vercel. Para "instalar" no seu aparelho:

1. Acesse o link do projeto pelo Chrome (Android) ou Safari (iOS).
2. Clique no menu do navegador e selecione "Adicionar à Tela Inicial".
   **Link do App:** https://superlista-rofd.vercel.app/
